# amp-hunter · 抗菌肽鉴定模型

**基于负样本偏倚控制与多源序列表征的抗菌肽（AMP）鉴定模型。**

抗菌肽是极具前景的抗生素替代方向。本项目针对 AMP 鉴定中普遍存在的**负样本偏倚**问题，结合多源序列表征方法构建鉴定模型；并附医学影像分类与分割的参考实现。

## 目录

| 目录/文件 | 说明 |
|---|---|
| `code/` | 抗菌肽模型主体代码（训练与评估） |
| `lv/` | 深度学习参考实现：AlexNet/ResNet 分类、脑肿瘤影像分类、肝脏 U-Net 分割 |
| `sixthweek/` | 早期迭代脚本 |
| `1.py-dir/` | 附加脚本 |
