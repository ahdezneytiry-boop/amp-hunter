# amp-hunter · 抗菌肽鉴定模型

**基于负样本偏倚控制与多源序列表征的抗菌肽（AMP）鉴定模型**（课程设计）。

抗菌肽是极具前景的抗生素替代方向。本项目针对 AMP 鉴定中普遍存在的**负样本偏倚**问题，结合多源序列表征方法构建鉴定模型；同时收录课程中的深度学习练习代码（CNN 分类、U-Net 分割等）。

## 目录

| 目录/文件 | 说明 |
|---|---|
| `daima/` | 抗菌肽模型主体代码（训练与评估） |
| `lv/` | 深度学习练习：AlexNet/ResNet 分类、脑肿瘤影像分类、肝脏 U-Net 分割 |
| `sixthweek/` | 第六周练习 |
| `1.py-dir/` | 附加练习脚本 |
